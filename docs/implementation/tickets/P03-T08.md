# P03-T08 — Persist state and pending effects as one transaction

Baseline `d32801a`.

## Interfaces

- `crates/rekuiper-core/src/reliability/outbox.rs` provides `SqliteOutbox`, `OutboxCapacity`, `OutboxEntry`, `EnqueueReport`, `OutboxError`, and `deterministic_effect_id`.
- Commits checkpoint metadata, source positions, participant state, and outbox entries in a single SQLite transaction, enforcing `max_items`/`max_bytes` capacity before admission, deduplicating repeated effect IDs (`INSERT OR IGNORE`), and scoping `claim_pending` by `(rule_id, action_id)`.

## Acceptance evidence

- `cargo test --locked -p rekuiper-core --test ticket_p03_t08` passed (rollback retains neither state nor effects, commit retains both, full capacity refuses admission, action-scoped claim preserves ownership, repeated insertion deduplicates).
- `cargo clippy --locked -p rekuiper-core --all-targets -- -D warnings` passed.
