# P02-T02 — Implement explicit lossy subscriber FIFO

## Summary

Added an opt-in `dropOldest` lossy subscriber FIFO (`rekuiper-core::resources::lossy_queue`) and integrated it into `StreamBus::subscribe_lossy` / `subscribe_lossy_filtered` with zero overhead on the default blocking `mpsc` fast path.
