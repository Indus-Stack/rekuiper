# P02-T07 — Bound asynchronous lookup concurrency

## Summary

Added bounded request/byte queueing, semaphore concurrency permits, `Clock`-based request timeouts, `DeadlineCancellation` propagation, and ordered-by-default batch execution in `rekuiper-server::engine::lookup_runtime`, and wired external async lookup paths in `rekuiper-server::engine::joins` through it.

## Changes

- [lookup_runtime.rs](file:///c:/Users/paanday/Documents/idacs/rekuiper/rekuiper-ticket-work/crates/rekuiper-server/src/engine/lookup_runtime.rs): Added `LookupRuntime`, `LookupQueueConfig`, `LookupOrderMode` (`Ordered` default, `Unordered` explicit opt-in), `LookupError`, and `LookupStatsSnapshot` backed by `ResourceBudget`, `Semaphore`, `Clock`, and `DeadlineCancellation` with RAII guards so errors, timeouts, and cancellations never leak permits or budget capacity.
- [joins.rs](file:///c:/Users/paanday/Documents/idacs/rekuiper/rekuiper-ticket-work/crates/rekuiper-server/src/engine/joins.rs): Routed async `redis`, `sql`, `modbus`, and `opcua` candidate lookups through `LookupRuntime::execute_one`, adding `lookup_candidates_with_runtime` and `apply_lookup_joins_with_runtime` while preserving baseline first-match join semantics.
- [mod.rs](file:///c:/Users/paanday/Documents/idacs/rekuiper/rekuiper-ticket-work/crates/rekuiper-server/src/engine/mod.rs): Exported `pub mod lookup_runtime;`.
- [ticket_p02_t07.rs](file:///c:/Users/paanday/Documents/idacs/rekuiper/rekuiper-ticket-work/crates/rekuiper-server/tests/ticket_p02_t07.rs): Verified bounded concurrency/queue overflow, zero permit/budget leaks on error/timeout/cancellation, ordered-by-default vs. explicit unordered batching, and first-match lookup join parity.
