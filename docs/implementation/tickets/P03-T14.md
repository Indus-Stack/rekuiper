# P03-T14 — Align multi-input barriers and async work

- **Owner:** `crates/rekuiper-server/src/engine/barrier_alignment.rs`
- **Status:** `component_done`
- **Tests:** `crates/rekuiper-server/tests/ticket_p03_t14.rs` (`cargo test --locked -p rekuiper-server --test ticket_p03_t14`)

## Summary
- Added `BarrierAligner<T>` to align checkpoint barriers across participating input edges, support idle edges without deadlock, and bound paused-edge buffers via `ResourceBudget`.
- Added async lookup tracking (`register_lookup`, `complete_lookup`, `snapshot_lookup`) so stalled lookups prevent barrier crossing and cancel cleanly on abort or timeout while releasing paused edges and budget reservations.
- Added `validate_acyclic_reliable_graph` to reject reliable feedback cycles in v1 and `ack_sink_completion` to track checkpoint completion across every reachable sink.
