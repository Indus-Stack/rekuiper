# P03-T01 — Implement atomic reliable SQLite storage

Baseline `dbb55ba`.

## Interfaces

- `crates/rekuiper-core/src/reliability/sqlite.rs` provides `ReliableSqliteStore` and `SqliteDurabilityMode` (`Full`, `Extra`) with versioned tables (`reliable_schema_meta`, `reliable_generations`, `reliable_checkpoints`, `reliable_positions`, `reliable_participants`, `reliable_outbox_effects`).
- `ReliableSqliteStore::open` enforces `journal_mode=WAL` (file DBs), `synchronous=FULL|EXTRA`, `foreign_keys=ON`, and reads back every PRAGMA to verify before returning.
- Implements `CheckpointStore`, `commit_with_outbox`, `outbox_record`, and `record_effect_completion` inside single atomic SQLite transactions with generation fencing.

- `cargo test --locked -p rekuiper-core --test ticket_p03_t01` passed against a file-backed SQLite database (verified read-back PRAGMAs, rollback on armed failure, stale generation rejection, idempotent effect completion, and exact reopen recovery).
- `cargo clippy --locked -p rekuiper-core --all-targets -- -D warnings` passed.
