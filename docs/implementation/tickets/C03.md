# C03 — Freeze clocks and ordered controls

Baseline `1db4d8bc7fbda87dd66d3b1bab40edbf07b4f8c5`.

## Interfaces

- `crates/rekuiper-core/src/contracts/clock.rs` provides `Clock`, `ClockReading`, `RealClock`, and `TestClock`. A clock supplies signed epoch milliseconds and elapsed monotonic time. `TestClock` shares its timeline across clones and advances explicitly. Both clocks implement `wait_until` with shared one-shot `DeadlineCancellation`. Custom clocks can await the token through its public `cancelled()` method. A wait returns `DeadlineCancelled` if it observes cancellation before completing.
- `LogicalDeadline` serializes as a signed epoch-millisecond integer. At restore, translate it using a reading from the new clock. Expired deadlines use the current elapsed value. Future deadlines saturate at `Duration::MAX` if the elapsed target cannot be represented.
- `crates/rekuiper-core/src/contracts/control.rs` provides `OrderedEnvelope<T>` with data, barrier, watermark, and end-of-input variants. An executor preserves order by sending all variants through the same FIFO queue. A plan-local `EdgeId` identifies watermark and end-of-input edges. `EventTimestamp` preserves its declared precision, including the full unsigned OTLP nanosecond range.
- `crates/rekuiper-core/src/contracts/mod.rs` exports the contracts through the core crate.

## Acceptance evidence

`crates/rekuiper-core/tests/ticket_c03.rs` covers deterministic advancement and waiter notification, shared and already-triggered cancellation including from a downstream clock implementation, real-clock immediate and extreme cancellable targets, restart conversion, integer extremes, and data/control order through one FIFO. Deterministic tests advance and poll explicitly.

Component complete. The independent Sol reviewer accepted the public cancellation API after a regression test verified it from a downstream clock implementation.

## Compatibility and follow-up

C03 adds contracts for reliable execution. The existing `StreamRecord`, `StreamReceiver`, and runtime paths keep their current interfaces. Monotonic targets belong to the clock that produced the reading. Translate a persisted logical deadline using a fresh clock reading after restart.

C04 uses these contracts for checkpoint participants and C05 uses them for changelog records. P03-T03 owns the reliable ingress queue, and P05-T01 owns watermark progression. Reliable v1 uses acyclic topologies.
