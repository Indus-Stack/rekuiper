# P01-T05 — Stop reporting success after schema persistence failure

- `crates/rekuiper-core/src/manager.rs` (`SchemaManager`) already persists to KV before updating in-memory state, so failed creates leave memory and KV empty, and failed updates/deletes preserve the prior active schema.
