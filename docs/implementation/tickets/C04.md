# C04 — Freeze state, checkpoint, and effect interfaces

Baseline `dbb55ba`.

## Interfaces

- `crates/rekuiper-core/src/contracts/state.rs` defines `STATE_ENVELOPE_VERSION` (`1`), `StateSchemaVersion`, `StateResourceUsage`, `StateSnapshot`, `StateError`, and `StateParticipant` for synchronous between-record capture on the operator owner task.
- `crates/rekuiper-core/src/contracts/checkpoint.rs` defines `CHECKPOINT_FORMAT_VERSION` (`1`), validated `ContentChecksum` (`sha256:<64 lowercase hex>`), `PlanIdentity`, `ParticipantSnapshotRef`, `OutboxBoundary`, `CheckpointMetadata`, `CheckpointEnvelope`, `CheckpointError`, and `CheckpointStore` with `validate_restore` checking version, rule/generation/plan/schema/extension fingerprints, participant completeness, checksum consistency, and source-position generation ownership.
- `crates/rekuiper-core/src/contracts/effect.rs` defines `EffectId`, `EffectDestination`, `EffectDeliveryBoundary` (keeping `DurableAccepted` distinct from `Delivered`), `EffectOutcome` (`Delivered`, `Retryable`, `PermanentFailure`, `Ambiguous`), `EffectRecord::record_completion` (idempotent terminal-outcome guard), `EffectDispatch`, and `EffectSink`.
- `crates/rekuiper-core/src/contracts/mod.rs` exports all three modules.
